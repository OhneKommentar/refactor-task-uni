# Agent instructions

- Implement only what the task or assignment asks for. Do not change, refactor or fix anything else, even if it looks wrong. Report such findings in the reply instead.
- Always test the result before calling it done: run the automated tests and verify the behavior manually in the running app. Report failures and skipped steps honestly.
- Change only what the assignment really requires or what is necessary for it.
- Always complete all extra and encouraged tasks (Zusatzaufgaben) that the assignment lists.
